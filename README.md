# 推推麻将

点一点、推一推的麻将消除小游戏原型。

- 在线试玩（最新版）：https://jarliao.github.io/tuitui-mahjong/
- 第一版（已冻结）：https://jarliao.github.io/tuitui-mahjong/v1/ ，源码见标签 `v1.0`

## 玩法

- **点消**：同一直线上、中间无遮挡的两张相同牌，点一下即消。
- **推牌**：按住一张牌拖动，它前面挨着的一整排牌会被一起推走，推到能配对的位置松手即消。附近 1.5 格内有配对位置会自动吸过去，快速一甩也能吸到。
- **石化牌**：推不动，也会挡住推动；把同样的牌推过去就能和它配对。
- **同牌高亮**：按下一张牌时，盘面上同样的牌会亮起描边。

## 两种模式

| | 爽玩 | 挑战 |
|---|---|---|
| 操作 | 点哪推哪：点一张不能直接配对的牌，自动挑最好的推法推过去 | 自己拖动推牌 |
| 连锁 | 推开后露出来的对子自动接连消掉，一路连锁 | 自己点 |
| 关卡 | 牌更少、石化牌减半、爆点更多 | 有难度，按「紧—松—中」循环 |
| 道具 | 不限次数，卡住自动洗牌 | 次数用完每次计时加 20 秒 |
| 计时与成绩 | 不计时，按最高连消给星 | 计时，记录每关最佳用时（留给以后的排行榜） |

两种模式进度分开保存，洗牌都保证洗完有解。

## 关卡设计（v2）

- 第 1 关是教学关，按「点消 → 推一张 → 推一整排」的顺序手把手引导；第 2 关巩固；第 3 关开始有挑战，之后按「紧—松—中」循环。
- 关卡从空盘倒推生成，每一步都是一个合法正向步的逆操作，所以必有解。
- 「闸门」结构：倒推时在一排空格两侧放几对隔空相见的牌，再把一排牌倒推回来塞进去挡住它们。正着玩就是先找到关键的那一排推开，随即露出好几对连着消。
- 每关离线生成一批候选，按开局现成对子数、模拟玩家必须自己推的步数占比、「一推露出好几对」的次数打分，挑最贴近目标的种子写进游戏。爽玩模式单独挑一套种子，只追求爆点多、开局松。

## 目录

```
src/game.html       游戏源码（单文件，规则引擎在 ENGINE-START/END 之间）
index.html          由 scripts/build.mjs 生成的独立网页（GitHub Pages）
v1/index.html       冻结的第一版
scripts/levels.mjs  离线挑关卡种子并写回 src/game.html
scripts/check.mjs   回归检查：标准解逐步回放、洗牌后必有解
scripts/build.mjs   生成 index.html
```

```bash
node scripts/levels.mjs 60   # 改了生成规则或难度目标后重新挑种子（可加 challenge 或 casual 只挑一种）
node scripts/check.mjs 60    # 回归检查
node scripts/build.mjs       # 生成 index.html
```

牌面为矢量自绘，音效由 WebAudio 实时合成，无外部素材。
